StrajaBackupSQL - bundled SQL client tools (Windows x64)

These are unmodified third-party executables invoked as separate processes.
No database servers, database installers, services or sample databases are included.
Each engine has a private directory under tools/. Libraries are not installed in
Windows system directories. Windows PATH and existing SQL installations are untouched.

MariaDB 11.4.10: mariadb.exe, mariadb-dump.exe and client authentication plugins.
Copyright MariaDB and other contributors. GNU GPL version 2 and component licenses.
Original notices: tools/mariadb/COPYING, CREDITS, THIRDPARTY, README.md.
Source: https://archive.mariadb.org/mariadb-11.4.10/source/mariadb-11.4.10.tar.gz

MySQL Community 8.4.11: mysql.exe, mysqldump.exe, client authentication plugins
and required libraries. Copyright Oracle and/or its affiliates and contributors.
GNU GPL version 2 and component licenses. Original notices: tools/mysql/LICENSE.
Source: https://cdn.mysql.com/Downloads/MySQL-8.4/mysql-8.4.11.tar.gz

PostgreSQL 18.6: psql.exe, pg_dump.exe and required libraries from the EDB binary
distribution (18.6-5). PostgreSQL license and third-party component licenses.
Original notices: tools/postgresql/server_license.txt and
tools/postgresql/commandlinetools_3rd_party_licenses.txt.
Source: https://ftp.postgresql.org/pub/source/v18.6/postgresql-18.6.tar.bz2

Microsoft Visual C++ Runtime 14.44.35211.0 (x64): unmodified redistributable DLLs
included in the official MariaDB archive. Copyright Microsoft Corporation.
Private app-local deployment; no system-wide runtime installer is executed.
https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files

Binary archive URLs, SHA-256 hashes and individual installed file hashes are in
tools/manifest.json. The packaging inputs are pinned in scripts/sql-tools.lock.json.
The corresponding MariaDB/MySQL source archives accompany this build in dist/sources.
When distributing the GPL executables, provide the corresponding source archives
alongside the binary download and preserve upstream notices and license terms.
Source archives are developer/distribution materials, not required for running the app.

Bundled versions do not guarantee compatibility with every server version or plugin.
A custom, compatible client directory can be selected in the advanced connection options.

Remote transfer client: rclone 1.75.2, unmodified Windows x64 executable.
Copyright Nick Craig-Wood and contributors. MIT license.
Project: https://rclone.org/ ; source: https://github.com/rclone/rclone/tree/v1.75.2
Original documentation and license: tools/transfer/README.txt, tools/transfer/COPYING.
Pinned archive provenance: scripts/transfer-tool.lock.json; installed tools/manifest.json.
The transfer client is private to StrajaBackupSQL and does not alter PATH or existing installations.
